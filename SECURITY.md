# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для актуального состояния ветки
`main`. Старые коммиты и отдельные ветки не поддерживаются.

## Как сообщить об уязвимости

Не публикуйте уязвимость, персональные данные, ключи, токены или подробности
эксплуатации в открытом Issue, Discussion или pull request.

Используйте приватный канал GitHub Security Advisories, если для репозитория
включён Private vulnerability reporting. Если он недоступен, напишите на
закрытый адрес поддержки, который оператор развернутого сайта задаёт в
переменной `ZOOLAND_SUPPORT_EMAIL`. Реальный адрес намеренно не хранится в
репозитории; перед публичным запуском владелец должен настроить эту переменную
и доступный приватный канал.

В сообщении укажите затронутую версию или commit, способ воспроизведения,
ожидаемое влияние и безопасный способ связи. Не прикладывайте реальные данные
пользователей. До согласования исправления не раскрывайте детали публично.
